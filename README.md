PIER HEAT — Sunset Bay: an original open-world crime game in a sunset coastal city, built for make.fun's "Make GTA 6" bounty. Play as Mateo Vega, getaway driver: steal the Scarlet Arrow on Ocean Drive, lose the Sunset Bay PD, and reach the pier safehouse before the sun drops. On foot and by car, with traffic and pedestrians, cars to steal, a wanted level and police, missions and a story, combat, a HUD with a minimap, a start screen and a save. All city, characters, vehicles, names, story, art, sound and music are original — nothing from Rockstar Games.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Controls: WASD drive/walk, E enter/steal car, F shoot, SHIFT boost, SPACE drift, P pause, R radio. Mouse look: click to lock, or drag.
